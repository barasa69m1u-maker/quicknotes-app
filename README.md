# QuickNotes App

## Description
QuickNotes is a dynamic, client-side web application designed to capture, categorize, search, and persist user notes locally. Built using vanilla JavaScript, modern CSS, and HTML5 semantic architecture, it ensures a smooth and responsive note-taking workflow.

## Features
- **Create Notes:** Add custom notes assigned to categories (Work, Personal, Ideas).
- **Validation:** Enforces length constraints (1–200 characters) with real-time error messaging.
- **Search Filtering:** Instantly filter notes dynamically as you type in the search bar.
- **Persistence:** Automatically saves and loads notes via browser `localStorage`.
- **Responsive Layout:** Optimized for mobile and desktop screens using Flexbox and CSS media queries.
